# AGENTS.md

Архив бейджей конференций: чистый статик без фреймворков и без сборщика — файлы из `src/` едут в `dist/` как есть. Рантайм-зависимостей ноль (ESM, Node ≥ 18). Контент и комментарии — на русском.

## Команды

- `npm run build` — валидация данных + сборка `dist/` + `manifest.json`. Это главный «тест»: именно его гоняет CI; ошибки валидации роняют build с exit 1.
- `npm run serve` — превью `dist/` на :4173 (поведение gh-pages, включая 404). Не открывать `dist/index.html` через file:// — fetch манифеста заблокирован CORS/file-политикой.
- `npm run preview` — build + serve одной командой.
- `npm run editor` — GUI-редактор карточек на :4174, пишет `meta.json` напрямую (2 пробела + newline).
- `npm test` — юнит фасеточного движка, без браузера (импортирует `src/assets/js/facets.js` напрямую, стабает `location`/`history`).
- `npm run test:browser` — Playwright-смоук. Требует уже запущенного `npm run serve` (:4173, или передать baseURL аргументом). Разовая установка: `npm i && npx playwright install chromium`.
- `node tools/test-editor.mjs` — e2e редактора. Требует запущенного `npm run editor` (:4174). Пишет и откатывает `addons/oz24-tbank/meta.json` — не держать этот айтем открытым в редакторе во время прогона.
- `npm run resize-images -- --dry-run` — пережатие картинок in-place (sharp, dev-зависимость). Перед боевым прогоном без `--dry-run` закоммититься: перезапись без бэкапа, git — единственный откат.
- `npm run migrate` сломан: скрипта `tools/migrate.mjs` не существует, в `package.json` остался хвост.

CI (`deploy.yml`, Node 22) гоняет **только build** — юнит и браузерные тесты в CI не входят, проверяй локально. Деплой: пуш в `main` → GitHub Pages.

## Структура

- Контент — это данные, не код: `badges/<event>-<year>/` и `addons/<slug>/`, в каждой папке `meta.json` + фото (`01.jpg`, `02.png`, …). Новый айтем = новая папка, код не трогаем.
- Все картинки папки попадают в галерею: сортировка по имени (numeric), первая = обложка; `cover` в meta.json переопределяет обложку.
- `site.config.json` — справочник `events` / `categories` / `rarities` (label, color, order) + список фасетов страницы `/addons/`. Ключи — lowercase-слаги, отображение — `label`.
- `tools/build.mjs`: валидация → `dist/manifest.json` (размеры картинок парсятся по магическим байтам) → `dist/` (сносится и пересобирается целиком; в `.gitignore`, руками не править и не коммитить).
- Фронт — ванильный JS: `src/assets/js/` (`core.js`, `cards.js`, `facets.js`, `modal.js`, `pages/`). Источник правды для модалки — `location.hash` (`#slug`), для фильтров — query (`?year=2025`): back закрывает модалку, ссылками можно делиться.
- Ленивая загрузка картинок — движок в `core.js` (`photo()`), НЕ нативный `loading="lazy"`. Один `sweep()`: near (±150px) — старт сразу с `high`; warm — упреждающий `low` на подлёте, зона = скорость скролла × 1.3s (900–3500px, скорость меряется в rAF-кадрах); idle тянет дальний хвост, когда юзер стоит. Инварианты (все выстраданы на реальном баге «строки пустые, пока не долистать до конца»): (1) отмена качающегося — только за 6000px или hidden — отмена «при nearPending» при непрерывном скролле вечна и косит всё за спиной; (2) качающихся не-near ≤ SOCKET_BUDGET (7): HTTP/1.1 даёт ~6 соединений, хвост может занять их все и near-старты заморозятся — лишние дальние качающиеся выбрасываются; (3) догнанная качающаяся low-картинка при дефиците сокетов перезапускается с `high` один раз — идущему запросу приоритет не поднять; (4) warm имеет гарантированные слоты, не делится с хвостом. Триггеры sweep: IO-батч, scroll/resize (rAF), load/error. Грабли: `img.complete === true` у img без `src`; detached/display:none — нулевые ректы. Все картинки через `photo()`. Воспроизведение багов: `tools/diag-hard.mjs [mbps]` — непрерывный скролл 2500px/s до конца + возврат с троттлом; на localhost без троттла всё вечно зелёное, полоса обязательна.
- Связи аддон ↔ бейдж автоматические по паре `(event, year)` — на бейдже появляются его аддоны.
- `tools/item-editor/server.mjs` ищет корень репо по маркеру `site.config.json` вверх по дереву, а не по относительному пути — при переносе файлов не хардкодить `../..`.
- `PHOTOS/` — сырые исходники фоток до обработки, в `.gitignore`, в архив не едут.

## Валидация (падает build = красный CI)

- слаг `^[a-z0-9][a-z0-9-]*$`, уникальный; у бейджа пара `(event, year)` уникальна;
- `event` / `category` / `rarity` обязаны существовать в `site.config.json`;
- у бейджа ≥ 1 фото (у аддона без фото — warning, будет плейсхолдер);
- `schematic` — если указан, строго URL с `http(s)://`, иначе ссылка уйдёт относительным путём на 404;
- неизвестные поля meta.json — warning (ловит опечатки вроде `manufaturer`);
- реальный формат файла сверяется с расширением по магическим байтам (webp в `.jpg` — warning).

## Хрупкости

- Браузерные и e2e-тесты хардкодят конкретные данные: аддон `oz26-ssti` (модалка с длинным URL в `test-browser.mjs`), бейдж `offzone-2020` (галерея ≥ 6 фото), `dc78422-2024` (голый URL в описании), `addons/oz24-tbank` («Капибара»), сетка > 90 карточек и дерево > 100 листьев. Переименовал/удалил эти айтемы — проверь тесты (см. историю: слаги аддонов чистили от `-addon-`, смоук молча падал).
- Аддон с `(event, year)`, для которых нет бейджа, — допустим (warning в логе), не «чинить».
